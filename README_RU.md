# Sudoku Graphite — Android APK без рекламы

Это исходный проект Android-приложения для судоку в тёмном графитовом оформлении.
Приложение не содержит рекламных SDK, аналитики, сетевых разрешений или встроенных покупок.
Сохранение игры и статистики выполняется локально на телефоне.

## Что уже реализовано
- Тёмный графитовый интерфейс
- Четыре уровня сложности
- Заметки в клетках
- Счётчик ошибок
- Таймер и сохранение текущей партии
- Статистика завершённых игр и лучший результат
- Облачная сборка APK через GitHub Actions

## Как собрать APK только с телефона

1. Скачай ZIP и распакуй его в доступное место.
2. Создай репозиторий на GitHub через браузер телефона.
3. Загрузи файлы проекта в репозиторий (можно через веб-интерфейс GitHub; удобнее сначала распаковать ZIP в облачной среде/на устройстве).
4. Открой вкладку **Actions** репозитория и разреши запуск workflows, если GitHub попросит.
5. Запусти **Build Sudoku Graphite APK** через **Run workflow**.
6. Когда сборка завершится успешно, открой её в Actions, прокрути до **Artifacts** и скачай `Sudoku-Graphite-debug-apk`.
7. Распакуй скачанный архив и установи `app-debug.apk` на Samsung. Если Android спросит, разреши браузеру/файловому менеджеру установку неизвестных приложений.

## Важно
Это первая рабочая версия проекта, но перед ежедневным использованием её нужно проверить на устройстве. Debug APK подходит для личной установки; для публикации в Google Play потребуется отдельная подписанная release-сборка.
